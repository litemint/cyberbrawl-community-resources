# Cyberbrawl Community Resources

Welcome to the official community resources repository for [Cyberbrawl](https://cyberbrawl.io). Cyberbrawl is a fast, competitive card battler built for players who want instant action. Set in a futuristic cyber-arena, every card represents advanced combat tech — droids, firewalls, hacking tools, overload modules — all fighting for tempo control.


## About

This repository contains community-generated documentation, including:
- 🌍 Translations
- 📡 REST API documentation
- 🎯 Strategy guides and game mechanics
- 🔧 Technical references

## Contributing

We welcome and appreciate all contributions! Here's how you can get involved:

1. **Submit documentation** — Share guides, strategies, or translations
2. **Report issues** — Found something that needs fixing? [Open an issue](https://github.com/litemint/cyberbrawl-community-resources/issues/new)
3. **Improve existing content** — Help us refine and expand our resources

Feel free to reach out through any of our channels below — we're here to help!
